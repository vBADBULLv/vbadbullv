# vBADBULLv – Website

Statische Website (GitHub Pages) für **vBADBULLv**, ein privates Tool, das meine eigenen Gameplay-Clips auf meine
eigenen Kanäle hochlädt. Enthält Startseite, Datenschutzerklärung, Nutzungsbedingungen, Datenlöschung und Kontakt –
jeweils auf Englisch (Wurzel) und Deutsch (`/de/`).

Seiten neu erzeugen: `python build.py <github-benutzername>`

Dieses Repository enthält keine Zugangsdaten. `client_secret*.json` und `token*.json` sind per `.gitignore` ausgeschlossen.
