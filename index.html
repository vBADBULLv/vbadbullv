vBADBULLv

Clip uploader for my own gameplay channels

vBADBULLv is a small personal desktop tool. It takes gameplay clips I recorded myself and uploads them – with title, description, tags and visibility – to my own channels and accounts, using each platform's official API and official sign-in.

Privacy Policy Terms of Service Data Deletion

What is vBADBULLv?

vBADBULLv is the name of my creator channels and of the small app I built to publish to them. The app runs locally on my own computer. It is not a public service: there is no sign-up, no user accounts, no server and no database. It is used only by me, the operator, to upload my own content to my own accounts.

  • Uploads video files I choose, with the title, description, tags and visibility I set (default: private).
  • Signs in only through the platform's own official login page (OAuth) – the app never sees passwords.
  • Never reads comments, messages, followers, analytics or anyone else's data.
  • No ads, no tracking, no selling or sharing of data.

How it works

  1. Record
    I record a gameplay clip on my PC.
  2. Describe
    I start the tool and enter title, description, tags and visibility.
  3. Sign in once
    The platform's official login opens in the browser. The access token is stored only on my computer.
  4. Upload
    The tool sends the video directly to the platform's official API – nothing goes anywhere else.

Platforms & permissions

YouTube active

YouTube Data API v3. Permissions: youtube.upload to upload videos and youtube.readonly only to confirm that the correct channel is signed in. This app uses YouTube API Services.

TikTok planned

TikTok Content Posting API – uploading my own clips to my own TikTok account (video.upload / video.publish).

Instagram planned

Instagram API content publishing – posting my own clips as Reels to my own professional account.

Twitch planned

Twitch API – limited to managing clips and videos on my own channel. Twitch does not offer video uploads via API.

Your data at a glance

The only data the app keeps is the sign-in token for each connected account, stored locally on my computer. Videos and their texts are sent directly to the platform I upload to. Details are in the Privacy Policy; how to remove access and data is explained on the Data Deletion page. Questions? Contact me.
