vBADBULLv

Clip-Uploader für meine eigenen Gameplay-Kanäle

vBADBULLv ist ein kleines, privates Desktop-Tool. Es lädt Gameplay-Clips, die ich selbst aufgenommen habe, mit Titel, Beschreibung, Tags und Sichtbarkeit auf meine eigenen Kanäle und Konten hoch – über die offizielle API und die offizielle Anmeldung der jeweiligen Plattform.

Datenschutzerklärung Nutzungsbedingungen Datenlöschung

Was ist vBADBULLv?

vBADBULLv ist der Name meiner Creator-Kanäle und der kleinen App, mit der ich dort veröffentliche. Die App läuft lokal auf meinem eigenen Computer. Sie ist kein öffentlicher Dienst: keine Registrierung, keine Benutzerkonten, kein Server, keine Datenbank. Nur ich als Betreiber nutze sie, um meine eigenen Inhalte auf meine eigenen Konten hochzuladen.

  • Lädt von mir ausgewählte Videodateien mit dem Titel, der Beschreibung, den Tags und der Sichtbarkeit hoch, die ich festlege (Standard: privat).
  • Anmeldung ausschließlich über die offizielle Login-Seite der Plattform (OAuth) – die App sieht nie ein Passwort.
  • Liest keine Kommentare, Nachrichten, Follower, Statistiken oder Daten anderer Personen.
  • Keine Werbung, kein Tracking, kein Verkauf und keine Weitergabe von Daten.

So funktioniert es

  1. Aufnehmen
    Ich nehme einen Gameplay-Clip auf meinem PC auf.
  2. Beschreiben
    Ich starte das Tool und gebe Titel, Beschreibung, Tags und Sichtbarkeit ein.
  3. Einmal anmelden
    Die offizielle Anmeldung der Plattform öffnet sich im Browser. Der Zugriffstoken wird nur auf meinem Computer gespeichert.
  4. Hochladen
    Das Tool sendet das Video direkt an die offizielle API der Plattform – sonst nirgendwohin.

Plattformen & Berechtigungen

YouTube aktiv

YouTube Data API v3. Berechtigungen: youtube.upload zum Hochladen und youtube.readonly nur, um zu prüfen, dass der richtige Kanal angemeldet ist. Diese App nutzt YouTube API Services.

TikTok geplant

TikTok Content Posting API – Hochladen meiner eigenen Clips auf mein eigenes TikTok-Konto (video.upload / video.publish).

Instagram geplant

Instagram-API (Content Publishing) – Veröffentlichen meiner eigenen Clips als Reels auf meinem eigenen professionellen Konto.

Twitch geplant

Twitch-API – beschränkt auf die Verwaltung von Clips und Videos auf meinem eigenen Kanal. Twitch bietet keinen Video-Upload per API.

Deine Daten auf einen Blick

Die App speichert nur den Anmelde-Token je verbundenem Konto, und zwar lokal auf meinem Computer. Videos und ihre Texte gehen direkt an die Plattform, auf die ich hochlade.
