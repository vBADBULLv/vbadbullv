Data Deletion

Last updated: 17 November 2026

What is stored

vBADBULLv has no server and no database. The only data it keeps is the sign-in token for each connected account, stored locally on the operator's computer. Uploaded videos live on the platform you uploaded them to and can be deleted there like any other post.

Option 1 – Remove access yourself

Revoking access makes the stored token useless immediately; the local copy is then deleted as well.

Google / YouTube

Open the Google security settings page (Third-party apps & services), select vBADBULLv and choose Delete all connections / Remove access.

TikTok

In the TikTok app: Profile → Menu (☰) → Settings and privacy → Security & permissions → Apps and services (or Manage app permissions), select vBADBULLv and tap Remove access.

Instagram / Facebook (Meta)

Instagram: Settings → Website permissions → Apps and websites → Active, select vBADBULLv and tap Remove. Facebook: Settings & privacy → Settings → Apps and websites, select vBADBULLv and choose Remove.

Twitch

Settings → Connections → Other connections, find vBADBULLv and click Disconnect.

Option 2 – Ask for deletion

Send an e-mail to vbadbullv@gmail.com with the subject “Data deletion request” and the platform and account name concerned. All data relating to that account is deleted within 7 days and you receive a confirmation by e-mail.
